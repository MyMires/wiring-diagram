# 制作器件模板

## 定义配件和端子

1. 核对已有模板和参考资料中的具体型号、端子次序和方向。更换实物或改变针脚定义时，建立新模板或新版本。
2. 在源码库的 `library/型号/版本/` 目录放置 `part.json`、`README.md` 和至少一种图面。模板 `id` 和 `version` 须与目录名一致。型号目录使用中文名称，保留实际型号和接口缩写。
3. 在 `ports` 中写稳定的端子 `id` 和 `name`。端子 ID 可使用英文字母、数字、下划线、加减号和斜杠。把已知的空接端子也纳入定义。实物资料只给出整口连接器时，可用 `"kind": "connector"` 保持原有粒度。修改端子时同步核对 `part.json`、图面锚点和可变通道配置。
4. `name` 和 `model` 分别提供图面默认名称和说明小字。用 `fields` 声明实例可填项。`station` 只有在 `fields` 中声明后才可使用，值为文本。实例级的位号、名称、备注和接线写在工程 JSON 中。

## 维护器件文档

每个模板版本在 `part.json` 旁维护自己的 `README.md`。文档标题写 `型号@版本`，至少说明用途、适用范围、主要端子的作用，并给出一段可放进 `instances` 的 JSON。模板有多种图面、参数或兼容行为时，说明选用方法、参数含义、默认值和适用限制。端子及图面可链接到同目录的定义与文件，完整端子列表用 `part` 查询。

新增或调整器件时，在对应版本内更新这些说明，并用 `part 型号@版本` 核对实例引用和示例参数。Skill 只维护模板格式和出图约束。具体型号、用法和示例随器件版本维护。

## 制作 SVG 符号

- `symbol.svg` 的 `viewBox` 从 `0 0` 起算。每个端子使用 `<circle>`，用 `data-port` 填端子 ID，用 `data-side` 填 `left`、`right`、`top` 或 `bottom`。`cx`、`cy` 写为绝对坐标，并与引脚 `<line>` 的一个端点重合。图形锚点与端子定义逐一对应。
- 保留器件局部图形，由出图器生成整页标题、实例位号和网络标签。由独立配件组成的线路按功能命名，省略「模块」后缀，直接绘制器件和连线，省略整组外框和底色。独立器件的实际轮廓按参考资料绘制。
- SVG 文字用 `data-text-role` 标记作用。内部位号用 `reference`，端子和整口连接器用 `terminal` 或 `interface`，说明用 `description`，急停用 `emergency`。端子文字与端子 ID 一致时，出图器自动沿用端子颜色。
- 内部导线和触点轮廓用 `data-circuit-role="wire"`，实心接点用 `data-circuit-role="junction"`。同类图形可以放在一个带标记的分组内。颜色由工程设置。[工程配色](projects.md#配置线路颜色)
- 同类管脚等距，对称触点列逐行对齐。通道之间留分隔空间，功能组之间增加留白。为缩放后的网名留出行距，让左右端子的短引线尽量水平直出。

## 制作实物照片模板

- 将确认过的照片和 `photo.json` 放在模板版本目录。`file` 指向目录内的照片，`ports` 以端子 ID 为键。`at: [x, y]` 从图像左上角归一化为 0–1，`side` 指定引线方向。把锚点落在实际螺丝端子、引脚或接口中心。
- 为 `part.json` 的全部端子建立照片锚点。符号与照片共用端子 ID，工程实例通过 `view` 选择图面。

## 配置参数和可变端子

- 用 `parameters` 公开可配置的整数参数，声明 `label`、`min`、`max` 和 `default`。记录参数范围依据、默认图面与有效端子的影响范围。
- 默认配置使用 `symbol.svg`。可变通道通过 `channel-layout.json` 定义行距、分组、端子模式和小字。识别并核对固定端子与可变端子，连通关系由工程网络定义。
- 仅替换内部位号时，在 `channel-layout.json` 的 `labels` 中声明格式，在对应 SVG `<text>` 上用 `data-parameter-label` 指向参数名。
- 用 `part` 检查默认值、边界值和代表性参数下的端子，再用包含相应端子的工程出图，核对布局、引线和标签。
