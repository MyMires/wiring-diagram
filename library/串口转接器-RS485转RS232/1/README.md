# 串口转接器-RS485转RS232@1

用于绘制此转接器的 RS485 A、B 接线，RS232 侧以 `DB9` 表示整口。

## 使用方法

默认使用符号视图。设置 `view: "photo"` 会使用模板随附的实物照片。两种视图均可引用 `converter.A`、`converter.B` 和 `converter.DB9`。

```json
{"id":"converter","reference":"X1","template":"串口转接器-RS485转RS232@1","sheet":"P01","view":"photo"}
```
